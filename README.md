# Census vs NSS Population Estimates Divergence

## Project Overview
Analytical assessment of divergence in population estimates 
between Census enumeration and NSS sample-based estimates.

## Key Areas Analysed
- Sampling design differences
- Weighting procedures
- Frame limitations
- Coverage errors
- Definitional variations

## Impact
Evaluated effect of divergence on demographic estimation 
and policy-level data reliability.

## Tools Used
- Statistical analysis
- Secondary data from Census and NSS
